# 反馈与诊断

现状：Windows 本机开发版 `0.1.3-dev` 已启用  
负责人：捞鱼  
最后更新：2026-11-10

## 反馈入口

主导航「遇到问题反馈」可直接打开表单。留言必填，问题类别选填。提交由桌面主进程发送，消息带应用名称、实际运行版本、平台、类别和留言。只在企业微信返回成功后提示收到。超时或拒收时保留表单，支持手动重试；一次只发送一条，成功后有 10 秒间隔。

诊断摘要默认勾选，可预览或取消。发送时取最近几条白名单记录，包含时间、事件名、状态与耗时。素材、文件名、目录、项目正文、账号和密钥不进入摘要。反馈正文仅在用户点击「发送反馈」时提交，代码不把反馈留言写入本机日志。

## 本机配置

`0.1.3-dev` 的 Windows 运行环境已按共享规范配置默认机器人。重新部署到另一台电脑时，开发者用同样的配置文件执行下面的命令。也可以指定一份只含当前产品专用机器人地址的私有配置文件。

```powershell
$exe = Join-Path $env:LOCALAPPDATA 'Programs/LaoyuCreatorStudio/0.1.3-dev/LaoyuCreatorStudio.exe'
$spec = 'E:/共享/tools/软件开发/软件组件/用户提意见&反馈.md'
Start-Process -FilePath $exe -ArgumentList @('--configure-feedback', ('"{0}"' -f $spec)) -WindowStyle Hidden -Wait
```

这个入口只在本机用 Electron 的系统凭证加密存储写入 `%LOCALAPPDATA%/LaoyuCreatorStudio/feedback-webhook.bin`，退出后重新打开正常程序即可读取。机器人地址仅在主进程使用。反馈配置和日志都留在运行目录，制品不携带这两项。缺少配置时表单允许复制留言，并提示当前无法投递。

## 日志与验收

- 设置 → 诊断可以查看、复制最近的日志，以及开启本次运行的排障模式。默认只记录操作摘要，开启后加记请求状态和耗时。
- 日志异步批量落盘，异常和退出时尽快写出。单份文件上限 256 KiB，轮换后保留上一份。画布导入期间显示剩余项数。
- `node --test tests/feedback.test.mjs` 验证认证、真实版本来源、UTF-8 长度、脱敏、关闭摘要、重复提交、上游失败和重试。
- 已用完整 Windows 开发包隔离验证加密配置、界面发送成功及失败分支、排障开关、正常退出写盘，以及关闭重开读回画布。本机真实企微群的收件回执尚待验证。
