# 剪映草稿往返

现状：基础明文草稿可导入，11.6 原生往返待实测  
负责人：捞鱼  
最后更新：2026-11-10

本机 Windows 登记的剪映专业版为 11.6.0.14552。公开工具已有原生草稿生成与读取实现。早期实现对新版加密草稿的模板能力受限，兼容分支给出的加密参考验证范围为 10.3.0–10.6.5，因此 11.6 的导出、打开、修改与读回需逐项实测。 [原版项目](https://github.com/GuanYixuan/pyJianYingDraft) · [兼容分支说明](https://github.com/aoguai/pyJianYingDraft/blob/main/README.md)

## 导出到剪映

- 工作台先检查目标系统、剪映版本、写入权限、媒体路径和能力表。预览哪些轨道或属性可编辑、哪些无法映射。
- 兼容时把当前采用版本输出为独立新草稿。基础验证范围为画面、音频、普通字幕、轨道顺序、片段源入出点、成片位置和音量。避免覆盖已有剪映草稿。
- 映射表保留项目版本、片段身份、媒体哈希和源/成片时间。使用源时间与哈希重连素材；复杂特效、关键帧、花字、云资源与字体缺失按实际表现明确记录。
- 只有通过真实剪映打开、编辑和保存测试的组合，才启用一键功能。遇不兼容时提供复制 Agent 指令及结构化时间线包。指令包含当前版本、素材及时间线包位置、素材引用、目标剪映版本、生成副本与回读要求。外部 Agent 也须拥有适配能力；不兼容时交回可移植剪辑单、字幕和素材映射。

## 从剪映导入

- 新项目入口可选择用户指定的剪映草稿目录。现有项目也可选择手改后的草稿导回。
- 只读识别草稿结构和本地媒体，导入成候选版本。比较片段、轨道、字幕、音量与时间位置，展示缺失或未映射项。读取失败时保留原件与当前时间线，提示确切原因。
- 已知导出映射优先使用。外部草稿的片段身份无法可靠对齐时，允许重新链接或作为新素材使用。未识别效果保留来源引用并告知无法编辑的部分，不承诺逐像素无损往返。

## 首轮验收

用合成素材在本机生成带三类基础轨道的新草稿，在剪映中实际打开。人工修剪一个镜头、调整 BGM 音量及字幕，保存后选回工作台。检查时长、帧位、字幕、音量和素材可播放。用工作台让 AI 只改另一个片段，复查人工改动保留，且原草稿副本未被覆盖。缺媒体、未知效果、不同草稿格式和保存中断分别验证。
