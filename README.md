# 捞鱼打标工具 🐟

> 给每一首 BGM 一个记得住的标签。边听边打标的本地小工具。

**发布页**：https://lyzbcy.github.io/laoyu-tagger/

## 这是什么

做 AI 漫剧/短视频的人常常有几百首配乐素材，但文件全是看不懂的哈希名，用的时候找不到。捞鱼打标工具把「听 → 记 → 找」变成流水线：

- 🎧 **边听边打标**：播放器 + 波形 + 倍速，情绪/场景/剧情标签点一下就打上
- 🔄 **剪映缓存自动同步**：自动监控剪映音乐缓存目录，新听的曲子自动入库
- 🧑‍🎓 **小白友好**：全中文傻瓜式启动器（缺 Node.js 回车即自动装）+ 首次自动教程 + ❓帮助中心
- 🤖 **AI 选曲**：把你的音乐清单+剧情打包成提示词，交给任意 AI 替你挑 BGM
- 🎵🔊 **音乐/音效分库**：分开管理、分开筛选、打包分文件夹
- ✨ **备注智能打标**：从备注文本按同义词增量补标签，绝不覆盖人工标签
- 📦 **一键整理导出**：`紧张·燃-对峙-铺垫_哈希.mp3` 标准名复制导出，不动原文件
- 🔗 **数据库联动**：JSONL 自动保存、自动重连、外部改动 5 秒同步

零安装、零依赖（需 Node.js）、数据纯文本永远属于你。

## 使用

1. 下载 zip 解压（发布页或本仓库 `Code → Download ZIP`）——**解压后第一层就是全部文件**
2. 双击 `启动打标工具.bat`（缺 Node.js？回车一下就自动装好，全程中文）
3. 跟着自动弹出的「30 秒新手教程」走一遍；忘了随时点「❓ 帮助」
4. 听歌、打标、写备注 → 「📦 整理导出」→ 「🤖 AI 选曲」让 AI 按剧情替你挑歌

详细说明见 [TOOL_README.md](TOOL_README.md)。

## 仓库结构

```
├── 启动打标工具.bat     ← 双击这里启动（停止打标工具.bat 一键停止）
├── launcher.ps1         ← 启动器本体（中文交互/自动装 Node.js，bat 负责唤起它）
├── START-HERE-启动说明.txt       ← 两步上手
├── index.html           ← 打标工具（单文件，无依赖）
├── sync-server.js       ← 同步服务器（剪映缓存监控 + 一键更新）
├── assets/stickers/     ← 表情贴纸（来自星星布丁精选表情包）
├── bgm_library.jsonl.template ← 数据库模板
└── docs/                ← 发布页（GitHub Pages，与本工具无关）
```
